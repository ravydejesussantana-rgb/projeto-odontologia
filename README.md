# Sorria Odontologia

Clínica odontológica moderna — desenvolvido pela Nexora Digital.

Página estática (HTML/CSS/JS puro), sem dependências de build.

## Publicar no GitHub Pages
1. Suba este `index.html` para um repositório no GitHub.
2. Vá em **Settings → Pages**.
3. Em "Source", selecione a branch `main` e a pasta `/ (root)`.
4. Salve. Em alguns minutos o site estará no ar.
